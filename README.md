# 에디터(PP_01_02_Editor)
이 프로젝트는 [Behind The Scene 시스템](https://github.com/Seok-Min-Lee/PP_01_00_Summary)의 **편집** 단계를 담당하는 클라이언트 프로그램입니다.</br>
Studio에서 촬영된 이미지를 불러와 얼굴을 인식하고, 마스크와 필터를 적용하여 전시에 사용할 이미지를 생성합니다.</br>
</br>
체험자는 Studio에서 받은 **세션 코드**를 입력하여 자신의 촬영 이미지를 서버로부터 전달받습니다.</br>
</br>
*데모 버전에서는 다운로드를 위한 QR코드를 제공하지 않습니다.
</br>
## 주요 기능
<ul>
  <li>세션 코드 입력을 통한 촬영 이미지 조회</li>
  <li>얼굴 랜드마크 인식</li>
  <li>얼굴 위치에 맞춘 마스크 및 필터 적용</li>
  <li>편집 완료 이미지를 서버로 전송</li>
</ul>
</br>

## 사용 기술
### 얼굴 인식
<ul>
  <li>라이브러리: Google MediaPipe</li>
  <li>기능: 얼굴 위치 및 랜드마크 추출</li>
  <li>설명: 추출된 얼굴 정보는 마스크를 얼굴에 맞게 정렬하는 데 사용됩니다.</li>
</ul>

### 네트워크
<ul>
  <li>통신 방식: TCP</li>
  <li>라이브러리: Telepathy</li>
  <li>설명: 촬영 이미지와 편집 결과 이미지는 서버와 이진 데이터 형태로 송수신됩니다.</li>
</ul>
